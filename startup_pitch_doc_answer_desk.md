## 1. Problem Statement

### Problem:
Organizations store critical information in scattered documents such as HR policies, onboarding guides, IT security procedures, finance rules, and department manuals. Employees waste valuable time searching through multiple files to answer simple operational questions.

### Target Users:
- HR teams
- New employees
- Team managers
- IT and compliance teams
- Small and mid-sized companies with many internal documents

### Current Solution:
People currently rely on:
- manual document searches across folders
- asking colleagues for answers
- email chains and chat messages
- static FAQs that quickly become outdated

### Pain Points:
- information is fragmented across multiple file types
- employees cannot find the correct policy quickly
- repeated questions waste productivity
- outdated or inconsistent document versions create confusion
- searching through PDFs, Word files, spreadsheets, and presentations is slow and frustrating

### Opportunity:
A smart AI assistant that understands internal company documents, answers natural-language questions, and cites the exact source document when responding can save time, reduce confusion, and improve employee productivity.

## 3. Product Definition

### Product Name
DocAnswer Desk

### What does it do?
DocAnswer Desk allows users to ask questions about internal documents in plain language and receive answers grounded in the provided files.

### Who is it for?
- employees who need quick policy clarification
- HR teams managing internal SOPs
- onboarding teams
- managers and compliance officers
- knowledge-heavy organizations

### What problem does it solve?
It eliminates the time spent manually searching multiple files and asking colleagues for answers.

### How does it work?
1. A user selects a folder or uploads documents.
2. The app reads supported file formats such as PDF, DOCX, XLSX, PPTX, TXT, MD, and CSV.
3. Relevant files are ranked using keyword-based retrieval.
4. Gemini analyzes the selected documents and answers the user’s query.
5. The system returns an answer with citations to the relevant file names.

### Why would someone use it?
Because it gives fast, trustworthy answers from official documents without requiring manual searching.

### What makes it different?
Unlike a generic chatbot, DocAnswer Desk is grounded in the user’s own document set and answers using only the provided source material. It is designed for business document knowledge, not general conversation.

### Product Value Proposition
For employees and teams who need quick answers from company documents, DocAnswer Desk is an AI knowledge assistant that retrieves accurate answers from internal files. Unlike basic search tools or generic chatbots, our product uses company documents as its source of truth and cites them directly.

## 10. AI Product / Prototype

### AI Functionality
The AI is not a generic chatbot. It is a document-grounded assistant that answers based on a company’s internal files.

### Input → AI Processing → Output
Input: user asks a question about HR policy, finance rules, IT access, or onboarding docs

AI Processing:
- load relevant documents
- filter by keywords and file relevance
- build prompt using source context and conversation history
- generate answer with citations

Output:
- direct answer
- bullet support points
- file references
- explanation of where the answer came from

### Example Questions
- “What is the notice period for a manager?”
- “How much annual leave can I carry forward?”
- “Who should I escalate a grievance to?”
- “What is the daily meal limit on business travel?”
- “What is the remote work policy for international travel?”

## 12. AI Data Pipeline

```text
DATA SOURCE
    ↓
DATA COLLECTION
    ↓
DATA CLEANING
    ↓
DATA STORAGE
    ↓
AI / LLM
    ↓
USER QUERY
    ↓
AI PROCESSING
    ↓
OUTPUT
```

### Data Source
Company policy documents, onboarding files, HR documents, and knowledge assets.

### Data Collection
Documents are gathered from local folders or uploaded files.

### Data Cleaning
- remove duplicate files
- normalize text
- remove corrupted or unreadable documents
- trim oversized files where necessary

### Data Storage
Stored locally in a folder or secure backend storage for processing.

### AI / LLM
Google Gemini is used to:
- rewrite the user question into useful retrieval terms
- score and select relevant files
- generate grounded answers from context

### User Query
The user types a natural-language question into the chat interface.

### AI Processing
The app retrieves relevant documents, builds a prompt, and generates a grounded answer using the selected context.

### Output
Answer with citations and supporting references.
