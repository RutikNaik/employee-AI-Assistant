# IT Security Policy

## Passwords

Employees must use strong passwords for company accounts.

Passwords must not be shared with colleagues or external parties.

Employees should not reuse their company password on personal websites.

## Multi-Factor Authentication

Multi-factor authentication must be enabled for company email, cloud services, and other systems that require it.

## Phishing

Employees should not open suspicious attachments or click unknown links.

Suspicious emails should be reported to the IT Security team.

## Public Wi-Fi

Employees should avoid accessing sensitive company systems through unsecured public Wi-Fi.

When working from public locations, employees should use an approved secure connection.

## Data Protection

Confidential company information must only be stored in approved company systems.

Employees must report suspected data breaches to IT Security immediately.
