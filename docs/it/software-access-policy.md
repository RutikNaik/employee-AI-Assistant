# Software and System Access Policy

## Access Requests

Employees who need access to a company application should submit a request through the IT service desk.

The request must include the business reason for the access.

## Approval

Application access may require approval from the employee's manager and the system owner.

## Access Removal

Access should be removed when an employee changes roles or leaves the company.

## Privileged Access

Administrative access is restricted to authorized IT personnel.

Privileged accounts must not be shared.

## Security

Employees must only access systems and information required for their job responsibilities.
